## 🚀 Features

### 🧑‍⚕️ For Users (Animal Owners)

- 📝 Register and log in  
- 🐶 Browse and view veterinarians' profiles  
- 📅 Book appointments  
- 🤖 AI Chatbot Consultation  
- 📖 View booking history  

### 🩺 For Veterinarians

- 🔐 Secure login  
- 🗓️ View upcoming appointments  
- 📋 Access booking details  
- 💰 View earnings  


### 🛠️ For Admins

- 🔐 Admin login  
- ➕ Add new vets with details  
- 📊 Monitor system activities  
- 📅 Manage all appointments  
- 📈 Generate daily report
